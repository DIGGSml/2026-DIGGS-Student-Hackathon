# Project Overview

Pile Stroke Log modernizes pile driving logging by replacing manual data entry with a mobile workflow that captures blow counts, stroke measurements, and project metadata in the field.

## Functional Areas
- Session setup for project metadata and pile context.
- Real-time stroke monitoring and interval-based logging.
- Optional bearing-capacity support calculation.
- Export of PDF summaries and DIGGS XML.
- Saved-project catalog with XML cloud sync status tracking.

## Interoperability
The DIGGS XML export path enables downstream ingestion and exchange of pile driving records with DIGGS-aligned systems.
